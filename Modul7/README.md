# Praktikum Pekan 07

Praktikum Modul 7 - Konsep Dasar Layout dan Styling.

## Menjalankan

```bash
flutter pub get
flutter run                                  # menu
flutter run -t lib/tugas_praktikum/main.dart # Soal 1-4 (Info Transit Kota Bandung)
flutter run -t lib/tes_akhir/main.dart       # Tes Akhir (Bandung Emergency 112)
```

## Struktur

| Path | Isi |
| --- | --- |
| `lib/main.dart` | Menu untuk membuka halaman praktikum |
| `lib/tugas_praktikum/main.dart` | Soal 1 header, Soal 2 status bar, Soal 3 armada, Soal 4 banner CCTV |
| `lib/tes_akhir/main.dart` | Tes Akhir Bandung Emergency 112 |
| `assets/images/terminal.png` | Gambar untuk banner CCTV |
| `test/widget_test.dart` | Uji tampilan dan uji anti-overflow footer |
| `Laporan/` | Laporan praktikum (.docx) |
| `laporan-assets/ray/` | Gambar potongan kode untuk laporan |
| `shots/` | Screenshot aplikasi untuk laporan |
